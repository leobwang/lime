# ONE ROW PER NUMBER, whitespace-delimited:
#
#     P<n>  <idiom>  <file>:<line>  <the divergence, in one line>

# `<idiom>` is which spelling the anchor line carries, and `parity.py` re-resolves it on

# gate requires P1..Pmax to be CONTIGUOUS: an index that is quietly 17 numbers short is what
# gap 1417 measured, and contiguity is what stops it happening again.  (This sentence and
